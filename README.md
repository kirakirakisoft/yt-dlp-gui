# yt-dlp GUI v3.3.0

**キラキラキソフト / KiraKiraKi Soft**

コマンド入力なしで [yt-dlp](https://github.com/yt-dlp/yt-dlp) を使うための、シンプルなGUIフロントエンドです。
「yt-dlpを使いたいけど、毎回コマンドを打つのは面倒・難しい」という方向けに作りました。

[English README is here → README_en.md](README_en.md)

---

## できること

- URLを貼ってボタンを押すだけでダウンロード
- **動画+音声(mp4)** / **音声のみ(mp3)** / **チャットのみ(`live_chat.json`)** の切り替え
- **時間指定ダウンロード**(必要な範囲だけ保存) — 全体を落とすときと**同じ最高画質**で切り出します
- **複数の範囲をまとめて切り出し** — 範囲を1行に1つ書くだけで、1回のダウンロードで全部切り出します(長時間配信から切り抜きを何本も作るとき、1本ずつやり直す必要がありません)
- **保存先フォルダの選択**(前回の設定を記憶します)
- 動画は **H.264(avc1)を最優先** で取得 — DaVinci Resolve などの編集ソフトでそのまま読み込める形式を狙います
- **使用する ffmpeg の指定** — 区間ダウンロードが正常に動く ffmpeg 7.1 系を明示できます(**時間指定を使う方は必須の設定です**。後述)
- **ダウンロード後の画質チェック** — 保存されたファイルの解像度とコーデックをログに表示。低画質で落ちてきた場合はその場で警告します
- メンバー限定・年齢制限動画のための **ブラウザCookie連携**(任意・初期設定はOFF)
- **プレイリスト一括ダウンロード**(ON/OFF切替。OFFのときはリストURLでも1本だけ落とす安全設計)
- **ライブ配信を最初から録画**(配信途中でも、配信開始まで遡ってダウンロード)
- **yt-dlpの自動更新**(ダウンロード失敗時に、確認のうえyt-dlpを最新版に更新して自動で再試行)
- リアルタイムのログ表示、ダウンロードの中止ボタン
- **アイコン画像のカスタマイズ** — `icon.png` を同じフォルダに置くと、ヘッダーとタスクバーに表示されます(**80x80以下の正方形PNG推奨** — そのままのサイズで表示されるため最も綺麗です。大きい画像は自動縮小されますが画質が粗くなる場合があります。なくても動きます)

## 必要なもの

| ソフト | 必須? | 用途 |
|---|---|---|
| Python 3.9以降 | 必須 | このアプリの実行 |
| yt-dlp | 必須 | ダウンロード本体 |
| ffmpeg **7.1系** | 必須 | 映像と音声の結合、mp3変換、時間指定ダウンロード(**8.1系では時間指定が動きません** — 下記) |
| Node.js | 任意 | 一部の動画の解析(なくても多くの動画は落とせます) |

### インストール手順(Windows)

1. **Python** — [python.org](https://www.python.org/downloads/) からインストール。
   インストーラー最初の画面で **「Add python.exe to PATH」に必ずチェック** を入れてください。
2. **yt-dlp** — コマンドプロンプトを開いて:
   ```
   pip install -U yt-dlp
   ```
3. **ffmpeg(7.1系を推奨)** — 手順は用途によって変わります。

   **▼ 時間指定ダウンロードを使う場合(7.1系が必須)**

   1. [GyanD/codexffmpeg の 7.1.1 リリースページ](https://github.com/GyanD/codexffmpeg/releases/tag/7.1.1) を開く
   2. 一番下の Assets から **`ffmpeg-7.1.1-full_build.zip`** をダウンロード
   3. zipを展開し、中身を `C:\ffmpeg-7.1` に配置
      (`C:\ffmpeg-7.1\bin\ffmpeg.exe` という場所になればOK)
   4. アプリの「**ffmpeg の場所**」欄に `C:\ffmpeg-7.1\bin` と入力(後述)

   **▼ 時間指定ダウンロードを使わない場合**

   ```
   winget install Gyan.FFmpeg
   ```
   (実行後、PCを再起動するか新しいコマンドプロンプトを開き直してください)

   > ⚠️ **`winget install Gyan.FFmpeg` で入るのは ffmpeg 8.1系です。**
   > 8.1系は結合やmp3変換には問題なく使えますが、**時間指定ダウンロードだけが
   > 動きません**(開始しても0バイトのまま進まず、いつまでも終わりません)。
   > これは ffmpeg 側の問題で yt-dlp では修正できないため
   > ([yt-dlp Issue #16546](https://github.com/yt-dlp/yt-dlp/issues/16546) —
   > `external-issue`)、7.1系を別途置いて指定するのが回避策です。
   > 8.1系はアンインストールしなくて構いません。並べて置いておけます。

4. **Node.js(任意)** — 一部の動画でエラーが出る場合のみ:
   ```
   winget install OpenJS.NodeJS.LTS
   ```

### 起動方法

`yt_dlp_gui.py` をダブルクリック、またはコマンドプロンプトで:

```
python yt_dlp_gui.py
```

※ ダブルクリック時に黒いウィンドウ(コンソール)を出したくない場合は、
ファイル名を `yt_dlp_gui.pyw` に変更してください。

起動時に yt-dlp / ffmpeg / Node.js を自動チェックし、足りないものはログ欄でお知らせします。

### ffmpeg の場所を設定する(時間指定を使う方は必須)

アプリ上部の「**ffmpeg の場所 (空欄で自動検出)**」欄に、7.1系を置いたフォルダを入力してください。

```
C:\ffmpeg-7.1\bin
```

入力して Enter を押すと設定に保存され、次回起動時も復元されます。
ログにこう出れば正しく認識されています。

```
ffmpeg: 検出OK (手動指定)
  パス: C:\ffmpeg-7.1\bin\ffmpeg.exe
  バージョン: 7.1.1-full_build-www.gyan.dev
```

- `C:\ffmpeg-7.1`(`\bin` なし)や、`ffmpeg.exe` 自体を指定してもかまいません
- **空欄のままだと PATH から自動検出します。** winget で入れた 8.1系がPATHに
  ある環境では、空欄 = 8.1系 = **時間指定が動かない**状態になります
- 時間指定を使わないのであれば、空欄のままで問題ありません

## 使い方

1. 動画のURLを貼り付ける
2. モード(動画 / 音声)を選ぶ
3. 必要なら時間指定をONにして、切り出したい範囲を入力(下記)
4. 「ダウンロード開始」を押す

### 時間範囲の書き方

**1行に1つ**書きます。複数書けば、その全部を**1回のダウンロードでまとめて**切り出します。

```
*00:12:00-00:27:00
*01:03:10-01:05:00
```

- 行頭の `*` は**有っても無くても**構いません
- `12:00-27:00` のように **分:秒**でも、`720-1620` のように**秒**でも書けます
- 終了に `inf` と書くと**動画の最後まで**になります(例 `*01:30:00-inf`)
- **空行**と、行頭が `#` の行は読み飛ばします(メモを書いておけます)

書いた範囲は、ファイル名の末尾に `[開始-終了]` として入ります。

```
配信タイトル [00-12-00-00-27-00].mp4
配信タイトル [01-03-10-01-05-00].mp4
```


ダウンロードが終わると、ログに実際の解像度が表示されます。

```
[確認] 実際の解像度: 1920x1080 / コーデック: h264
```

480p以下だった場合は警告を出します(元動画がその画質しか無い場合もあります)。

保存先は「変更...」ボタンでいつでも変えられます。設定は自動で記憶されます。

各トグルの「(?)」マークにマウスを乗せると、機能の説明が表示されます。

### ライブ配信を最初から録画する

「ライブ配信」のトグルをONにすると、配信中のライブに途中から入っても、
**配信開始時点まで遡って**ダウンロードします。

- この機能が使えるのは、**配信側がアーカイブ(見逃し配信)を残す設定にしている場合のみ**です。アーカイブが無効な配信は遡れません。
- 配信開始まで遡る分、ダウンロードに時間がかかることがあります。

### yt-dlpの自動更新

動画が落とせない原因の多くは、yt-dlp本体が古くなっていることです(各プラットフォームの仕様変更に追いつくため、yt-dlpは頻繁に更新されます)。

- **自動更新トグルOFF(初期状態)**:ダウンロードに失敗すると「yt-dlpを最新版にアップデートしますか?」と確認するダイアログが出ます。「はい」を押すと更新して自動で再試行します。
- **自動更新トグルON**:確認なしで自動的に更新→再試行します。毎回確認するのが面倒な方向けです。
- 更新は `pip install -U yt-dlp` 相当の処理を行います。権限などの理由で自動更新に失敗した場合は、手動での更新方法をログに案内します。

## ブラウザCookie機能について(重要)

メンバー限定動画や年齢制限付き動画など、**ログインが必要なコンテンツ**をダウンロードする場合のみ使う機能です。初期設定はOFFです。

- **Firefox推奨**:Chrome系ブラウザは近年Cookieの暗号化が強化されており、
  外部ツールからの読み取りに失敗しやすいためです。Firefoxで対象サイトに
  ログインした状態でONにしてください。
- **自己責任でお使いください**:ログイン状態でのダウンロードツール使用は、
  プラットフォーム側に自動化ツールの利用として検知され、**アカウントに
  制限がかかる可能性がゼロではありません**。心配な場合はメインアカウント
  ではなくサブアカウントの使用を検討してください。
- このアプリがCookieを外部に送信することはありません。Cookieは
  お使いのPC内で yt-dlp に渡されるだけです。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「yt-dlp が見つかりません」と出る | `pip install -U yt-dlp` を実行。それでも出る場合はPythonインストール時のPATH設定を確認 |
| 映像と音声がバラバラに保存される / mp3にならない | ffmpegが未導入です。上記手順でインストール |
| **時間指定ONにすると、ずっと0バイトのまま進まない** | **ffmpeg 8.1系が原因です。**7.1系を導入して「ffmpeg の場所」に指定してください(上記手順3) |
| 「時間指定を使うには ffmpeg が必要です」と出て止まる | ffmpegが見つかっていません。「ffmpeg の場所」欄に7.1系のフォルダを入力してください |
| 落としたのに解像度が低い(360pなど) | 元動画がその画質しか無い可能性が高いです。v3.3.1未満をお使いの場合は、時間指定時に360pになる不具合があるため最新版に更新してください |
| 4K動画なのに1080pで落ちてくる | 仕様です。編集ソフトでの互換性を優先してH.264を選ぶため、上限が1080pになります(4K/1440pはVP9・AV1のみでH.264版が存在しません) |
| `ERROR: Sign in to confirm...` 系のエラー | Cookie機能をONにして再試行(Firefoxでログインしておくこと) |
| 一部の動画だけ `ERROR` になる | Node.jsを導入すると解決する場合があります。また `pip install -U yt-dlp` で最新版への更新も試してください |
| 文字化けしたファイル名になる | ご利用の環境のシステムロケールをUTF-8に設定すると改善する場合があります |
| 昨日まで動いていたのに急に落とせなくなった | プラットフォーム側の仕様変更の可能性が高いです。まず `pip install -U yt-dlp` で更新してください |

## 更新履歴

- **v3.3.0** — **複数の時間範囲を一度に指定できるようにした。**時間指定を「開始」「終了」の2欄から複数行の入力欄に変更し、`*00:12:00-00:27:00` の形式をそのまま貼り付けられるようにした(`*` 無し・分:秒・秒・`inf` も可)。書いた範囲は1回のダウンロードでまとめて切り出す。出力ファイル名に区間の開始/終了が入るようになり、複数区間が同名で消える問題も解消。あわせて、**時間指定ONのとき画質が必ず360pに落ちていた不具合を修正**(旧版は結合済みmp4のみを対象にしていたため、YouTubeでは640x360固定になっていた)。区間切り出し中にログが止まって見える問題を修正。ダウンロード完了後に実ファイルの解像度・コーデックをログ表示。**使用する ffmpeg のフォルダを指定できる欄を追加**(**ffmpeg 8.1系では時間指定ダウンロードが動かない**ため、7.1系を指定して回避する。8.x のときは開始前に警告を出す)。起動時ログに使用中のffmpegのパスとバージョンを表示
- **v3.2.1** — 「チャットのみ」モード(配信チャットを `live_chat.json` として保存)を追加。UIのフォントを日本語向け(Yu Gothic UI / BIZ UDGothic)に変更
- **v3.2** — プレイリスト一括ダウンロード(ON/OFF)、ライブ配信を最初から録画する機能、ダウンロード失敗時のyt-dlp自動更新(確認ダイアログ/自動の切替)、各トグルのマウスホバー説明(ツールチップ)を追加
- **v3.1** — 右クリックメニュー(貼り付け/消して貼り付け/コピー等)、icon.pngによるアイコンカスタマイズ、サイレント起動用の .pyw 版を同梱
- **v3.0** — 配布版として公開。保存先フォルダ選択+設定記憶、Cookie機能の
  ON/OFF化とブラウザ選択、依存ツールの起動時チェック、ダウンロード中止
  ボタン、URL/時間入力の検証、グラデーションヘッダーを追加
- v2.x — 個人利用版(H.264優先フォーマット、フリーズ対策、UTF-8対応)
